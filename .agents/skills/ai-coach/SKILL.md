# AI Coach Skill

Before modifying AI coaching:

1. Read docs/AI-COACH.md.
2. Read docs/LEARNING-DESIGN.md.
3. Preserve the think-before-help interaction.
4. Keep model output structured.
5. Validate model responses.
6. Keep secrets server-side.
7. Test fallback/error states.
8. Never turn the coach into an unrestricted chatbot.
