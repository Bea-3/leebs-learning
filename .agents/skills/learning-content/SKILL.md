# Learning Content Skill

When working with learning content:

1. Read docs/LEARNING-DESIGN.md.
2. Preserve learning objectives.
3. Keep lessons short and mobile-friendly.
4. Prefer active learning over passive explanation.
5. Attach source metadata where available.
6. Never describe generated questions as official past questions.
7. Separate factual content from presentation.
8. Design questions to test understanding rather than memorization.
