# Leebs — Learning Design

## Philosophy

Leebs is designed around active understanding rather than passive
content consumption.

The application should encourage learners to:

- retrieve information
- explain reasoning
- notice misconceptions
- revise mental models
- apply concepts to new situations
- reflect on learning

## Learning Unit

The smallest learning unit is a micro-lesson.

A micro-lesson contains:

- learning objective
- explanation
- example
- optional visual
- quick check
- assessment
- reflection

Target duration:

5–10 minutes.

## Assessment Flow

### Correct answer

Correct
→ brief feedback
→ transfer/next question
→ mastery evidence

### Incorrect answer

Incorrect
→ ask for reasoning
→ learner explains
→ diagnose misconception
→ AI guidance
→ learner responds
→ transfer question
→ mastery evidence

## Reflection

Reflection should be lightweight.

Examples:

"Explain this idea in your own words."

"What was confusing at first?"

"What helped the concept make sense?"

"How would you explain this to a friend?"

Reflection should not feel like homework added after learning.

## Mastery

Mastery is concept-based.

States:

### Needs Practice

Learner has not yet demonstrated understanding.

### Developing

Learner shows partial understanding or requires significant guidance.

### Understanding

Learner successfully applies the concept after limited guidance.

### Strong

Learner demonstrates the concept correctly across repeated or
transfer questions.

MVP mastery logic can be deterministic.

Do not require AI to calculate mastery.

## Feedback

Good feedback should:

- acknowledge useful reasoning
- identify the gap
- avoid shame
- provide the smallest useful hint
- encourage another attempt

Avoid:

"Wrong."

Prefer:

"You're thinking about the right relationship, but there's one part
to reconsider."

## Product Principle

The learner should do meaningful cognitive work before the system
does it for them.

## Micro-Learning Content Constraints

Leebs should not feel like a digital textbook.

Present one primary idea at a time.

For normal learning steps:

- target approximately 40–80 words
- use short paragraphs
- prefer examples and simple diagrams where they reduce explanation
- avoid unnecessary introductory text
- progressively reveal concepts rather than presenting long lesson pages
- provide one obvious primary action per screen

The learning rhythm should generally be:

Idea → Example → Think → Act → Continue

AI coaching should also be concise.

Prefer 2–4 short sentences or one focused question at a time.

Clarity is more important than completeness on any individual screen.
Complex concepts should be broken into multiple learning steps rather
than explained in one large block.

Concise must not become childish. The primary learner is a teenager.
